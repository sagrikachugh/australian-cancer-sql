From workbook to report

The project is designed to demonstrate SQL in context: data modelling, analytical queries, quality assurance and clear communication of limitations.

01 · CLEAN

Prepare the data

Download and validate the official AIHW workbooks, then standardise fields in R.

02 · MODEL

Load DuckDB

Create typed incidence, mortality and cancer-dimension tables with explicit keys.

03 · QUERY

Analyse with SQL

Use CTEs, joins, parameters and window functions to answer six questions.

04 · VERIFY

Test and report

Run SQL quality checks and automated tests before rendering the Quarto output.
